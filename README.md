# Minesweeper Game

A simple Minesweeper desktop game developed in Python using Tkinter for the graphical user interface (GUI).  
Players reveal cells on a 9×9 grid, avoid hidden mines, and use numerical clues to identify safe cells.  

The game includes flagging, automatic cell revealing, win/loss detection, and a New Game option.

**Technologies:** Python, Tkinter, Random Module

**Learning Objectives:** Practice Python functions, lists, nested loops, event handling, conditional logic, and basic GUI development.
